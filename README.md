# Craft & Find — Forge 1.20.1

Отдельный бэкпорт Craft & Find для **Minecraft 1.20.1 + Forge 47.2.0**. Исходная версия NeoForge 1.21.1 не используется во время сборки и не изменяется этим проектом.

- **Mod ID:** `craftandfind`
- **Автор:** `overyourhead`
- **Java:** 17
- **Версия:** `0.1.7-forge-1.20.1`

## Что сохранено

- Складской верстак как мультиблок 2×2, включая корректную установку, разрушение и дроп.
- Приватная постоянная сетка крафта 3×3 для каждого игрока, измерения и конкретного верстака.
- Все фиксы сохранения сетки после закрытия GUI, выхода, смерти, разрушения и замены блока.
- Поиск предметов в ближайших ванильных `Container`, суммарные количества, поиск, сортировка и прокрутка.
- Крафт с расходованием предметов сначала из игрока, затем из ближайших хранилищ; начатые стаки расходуются раньше.
- Ванильная книга рецептов с оформлением Craft & Find и ghost-рецептами для недоступного крафта.
- Оптимизированное сканирование контейнеров, обновление содержимого и подавление одинаковых сетевых снимков.
- Подсветка всех подходящих контейнеров, выбор главного по количеству и расстоянию, звуки и частицы.
- Двойные обычные и ловушечные сундуки учитываются как единая визуальная область.
- Главный маркер с рамкой и 3D-предметом, плавным появлением/затуханием и полупрозрачным отображением через стены.
- За стеной частицы не отображаются; вертикального покачивания маркера нет.
- Клиентский и серверный TOML-конфиги с теми же настройками и значениями по умолчанию.
- Исходные модели, текстуры, локализации, рецепты, достижения и звуки интерфейса.

## Сборка

В проекте есть `gradlew` и `gradlew.bat`. Если стандартный `gradle-wrapper.jar` отсутствует, скрипт при первом запуске сам скачает Gradle 8.1.1 в пользовательский кэш.

Windows:

```bat
gradlew.bat build
```

Linux/macOS:

```bash
./gradlew build
```

Готовый мод появится в:

```text
build/libs/craftandfind-0.1.7-forge-1.20.1.jar
```

Для запуска тестового клиента:

```bat
gradlew.bat runClient
```

Для тестового выделенного сервера:

```bat
gradlew.bat runServer
```

Первый запуск Gradle также скачает Forge, mappings и зависимости Mixin.

## Конфиги

Клиентский конфиг:

```text
.minecraft/config/craftandfind-client.toml
```

Серверный конфиг отдельного мира:

```text
.minecraft/saves/<world>/serverconfig/craftandfind-server.toml
```

На выделенном сервере:

```text
<server>/world/serverconfig/craftandfind-server.toml
```

## Совместимость хранилищ

На данном этапе сканируются блок-сущности, реализующие ванильный `Container`. Ванильные сундуки, бочки, печи, воронки, раздатчики и похожие контейнеры поддерживаются. Инвентари модов, доступные только через Forge `IItemHandler`, пока не сканируются.
