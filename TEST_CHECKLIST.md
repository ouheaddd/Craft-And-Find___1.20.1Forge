# Матрица тестирования Forge 1.20.1

## 1. Сборка и загрузка

- [ ] `gradlew.bat clean build` завершается без ошибок на Java 17.
- [ ] Клиент запускается через `gradlew.bat runClient`.
- [ ] Выделенный сервер запускается через `gradlew.bat runServer`.
- [ ] Клиент подключается к серверу с тем же JAR.
- [ ] В логах нет ошибок Mixin, отсутствующих текстур, моделей, рецептов или пакетов.

## 2. Блок и мультиблок

- [ ] Складской верстак появляется в творческом меню после стола зачарований.
- [ ] Установка создаёт ровный мультиблок 2×2.
- [ ] Установка отменяется, если хотя бы одна из четырёх позиций занята.
- [ ] Открытие любой части вызывает один и тот же GUI.
- [ ] Разрушение любой части удаляет весь мультиблок.
- [ ] В выживании выпадает ровно один предмет верстака.
- [ ] В творческом режиме лишний предмет не выпадает.
- [ ] Замена части другим блоком не оставляет невидимых частей.

## 3. GUI и книга рецептов

- [ ] GUI совпадает по расположению с версией 1.21.1 при GUI Scale 2, 3 и 4.
- [ ] Слот результата, сетка 3×3 и инвентарь игрока выровнены с текстурами.
- [ ] Вкладки компаса и книги переключаются без скачков.
- [ ] Поиск, фильтр, категории и перелистывание книги рецептов работают.
- [ ] Кнопки и карточки рецептов используют текстуры Craft & Find.
- [ ] Ghost-рецепт отображает ингредиенты в правильных девяти слотах.
- [ ] Изменение размера окна не ломает расположение компонентов.

## 4. Панель хранилища

- [ ] Отображается сетка 5×5 найденных типов предметов.
- [ ] Суммарные количества совпадают с фактическим содержимым контейнеров.
- [ ] Значения выше 512 отображаются как `512+`.
- [ ] Поиск работает по локализованному имени и registry ID.
- [ ] Алфавитная сортировка включена по умолчанию.
- [ ] Сортировка `64` упорядочивает по количеству.
- [ ] Запрос поиска и режим сортировки сохраняются до закрытия Minecraft.
- [ ] Прокрутка работает при количестве типов больше 25.

## 5. Крафт из хранилищ

- [ ] Доступность рецептов учитывает инвентарь игрока, сетку и ближайшие контейнеры.
- [ ] Авторазмещение сначала использует предметы игрока, затем контейнеров.
- [ ] В контейнерах сначала расходуются начатые стаки.
- [ ] Рецепт с материалами из нескольких контейнеров размещается корректно.
- [ ] Shift-клик результата создаёт максимально возможное количество без дюпа.
- [ ] Изменение содержимого сундука сразу после открытия GUI не создаёт предметы из воздуха.
- [ ] Недоступный рецепт показывает ghost-ингредиенты и не извлекает предметы.

## 6. Постоянная сетка 3×3

- [ ] Сетка сохраняется после обычного закрытия GUI.
- [ ] Сетка сохраняется после выхода и повторного входа в мир.
- [ ] Два разных верстака хранят разные раскладки одного игрока.
- [ ] Два игрока имеют независимые раскладки одного верстака.
- [ ] Смерть игрока не дублирует и не выбрасывает сохранённую сетку.
- [ ] Разрушение верстака корректно очищает/возвращает его сетку согласно текущей логике.
- [ ] Повторная установка по тем же координатам не восстанавливает старую раскладку.
- [ ] Верстаки с одинаковыми координатами в разных измерениях независимы.

## 7. Сканирование и конфиг

- [ ] `searchRadius` меняет реальный радиус поиска.
- [ ] `containerScanIntervalTicks` меняет интервал полного пересканирования.
- [ ] `contentRefreshIntervalTicks` меняет частоту обновления содержимого.
- [ ] `maxHighlightedContainers` ограничивает только визуальные цели, не поиск и не крафт.
- [ ] Одинаковые снимки не вызывают постоянного сетевого спама.
- [ ] После крафта и запроса подсветки состояние обновляется без ожидания полного интервала.

## 8. Двойные сундуки

- [ ] Обычный двойной сундук считается одной визуальной целью.
- [ ] Сундук-ловушка также считается одной визуальной целью.
- [ ] Количество складывается из обеих половин.
- [ ] Маркер расположен в центре всей области 2×1 или 1×2.
- [ ] Частицы охватывают обе половины и не дублируются отдельными облаками.

## 9. Подсветка

- [ ] ЛКМ по предмету закрывает GUI и запускает подсветку.
- [ ] Все контейнеры с предметом получают частицы.
- [ ] Главным становится контейнер с максимальным количеством; при равенстве — ближайший.
- [ ] Звуки проигрываются максимум у трёх целей.
- [ ] Главный маркер содержит рамку и правильный 3D-предмет.
- [ ] Маркер не качается вверх-вниз.
- [ ] При быстром стрейфе и вращении камеры маркер не дрожит заметно.
- [ ] Без стены рамка и предмет ведут себя как обычный маркер.
- [ ] За стеной рамка и предмет остаются видимыми с пониженной прозрачностью.
- [ ] За стеной частицы главной и вторичных целей не просвечивают.
- [ ] Рамка и предмет плавно исчезают одновременно.
- [ ] Основная длительность и дополнительное время частиц соответствуют клиентскому конфигу.
- [ ] Отключение маркера, частиц или звуков в конфиге работает независимо.

## 10. Мультиплеер

- [ ] Подсветку видит только игрок, который её запросил.
- [ ] Один игрок не получает сетку крафта другого.
- [ ] Одновременное открытие верстака двумя игроками не создаёт дюпы.
- [ ] Сервер отклоняет устаревшее или невозможное извлечение из контейнера.
- [ ] Переподключение не оставляет старую клиентскую подсветку или снимок хранилища.
